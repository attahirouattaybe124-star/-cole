# EcoleHub SaaS

Plateforme de gestion scolaire - République de Guinée

## Deploiement Netlify

1. Creer un compte sur netlify.com
2. "New site from Git" -> connecter GitHub
3. Build command: `npm run build`
4. Publish directory: `dist`
5. Deploy!

## Developpement local

```bash
npm install
npm run dev
```
